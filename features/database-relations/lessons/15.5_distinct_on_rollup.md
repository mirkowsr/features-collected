# Lesson 15.5 — DISTINCT ON & ROLLUP / GROUPING SETS

**Goal:** Two PostgreSQL superpowers — "latest row per group" in one scan, and multi-level totals in one query.

---

## Theory

### DISTINCT ON — top-1 per group, the easy way

`SELECT DISTINCT` removes duplicate **rows**. `SELECT DISTINCT ON (cols)` keeps **one row per group** — the first according to your `ORDER BY`:

```sql
SELECT DISTINCT ON (customerid)
       customerid, orderid, orderdate, sales
FROM sales.orders
ORDER BY customerid, orderdate DESC;
```

Read it as: "for each customer, the row with the newest `orderdate`." Rules:

- The `DISTINCT ON` columns must be the **leftmost** `ORDER BY` columns.
- The remaining `ORDER BY` columns decide *which* row wins (here: newest first).

The textbook alternative (subquery on `MAX(orderdate)` per customer, lesson 16) needs two passes and more code. `DISTINCT ON` is one scan — and a partial sort.

### ROLLUP — subtotals up the hierarchy

`GROUP BY ROLLUP (a, b)` groups by `(a, b)`, then by `(a)`, then by `()` (grand total) — in **one** query:

```sql
SELECT country, city, SUM(sales)
FROM ...
GROUP BY ROLLUP (country, city);
-- rows: per city, per country (city = NULL), grand total (both NULL)
```

### GROUPING SETS & CUBE

| Clause | Produces |
|--------|----------|
| `ROLLUP (a, b)` | (a,b), (a), () — a hierarchy |
| `CUBE (a, b)` | (a,b), (a), (b), () — **all** combinations |
| `GROUPING SETS ((a), (b), ())` | exactly the sets you list |

Distinguish subtotal rows (where a column is `NULL` because it's aggregated away) from real NULLs with `GROUPING(col)` — returns `1` on subtotal rows.

---

## Worked example — latest order per customer + sales report

```sql
-- each customer's most recent order
SELECT DISTINCT ON (o.customerid)
       c.firstname, o.orderid, o.orderdate, o.sales
FROM sales.orders o
JOIN sales.customers c ON c.customerid = o.customerid
ORDER BY o.customerid, o.orderdate DESC;

-- revenue by category and status, with subtotals
SELECT p.category,
       o.orderstatus,
       SUM(o.sales) AS total
FROM sales.orders o
JOIN sales.products p ON p.productid = o.productid
GROUP BY ROLLUP (p.category, o.orderstatus)
ORDER BY p.category NULLS LAST, o.orderstatus NULLS LAST;
```
